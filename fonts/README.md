# Fonts

## Bebas Neue (`BebasNeue-Regular.ttf`)

The headline typeface. Copyright 2019 The Bebas Neue Project Authors (https://github.com/dharmatype/Bebas-Neue).

It is licensed under the SIL Open Font License, version 1.1. The full text is in `BebasNeue-OFL.txt`, beside this file. The licence allows the font to be used, copied and shared, including on a website, as long as it is not sold on its own and the licence stays with it.

The University's brand guidelines name Bebas Neue Pro, a paid family from the same designer with more weights and lower-case letters. Bebas Neue is the free original. In capitals, which is how the guidelines use it for headlines, the two look the same.

This is the same file the Tech Practice Hub uses.

## Univers

The University's all-round typeface. It is a commercial typeface, so there is no copy in this folder.

`css/site.css` asks for Univers by name. A computer that has it installed shows it. Any other computer shows Helvetica Neue, Helvetica or Arial, which are close in shape.
